#### Combos

Spinarak + Tangela / Octillery / Tentacruel
1. use Spinarak "Websling" 
	( tangle foe and switch into another pokemon )
2. use "Binding Blow"
	( deals bonus damage to tangled pokemon )
- Tangela has access to only bad tangle moves

Koffing + Smoke Cover
1. use Smogon "Smokestack"
	( concentrating: each turn inflict enemies with smoke poisoning )
2. use assist "Smoke Cover" by Crobat
	( active pokemon has highly increased evasion this turn only )

Slugma + Charmander
1. use Slugma "Heat On"
	 ( give 3 pokemon in your team 1 heat ) ( heat increases speed of fire moves)
2. use Charmander "Blow Torch"
	( consume 1 heat to deal bonus damage )

Drowzee + Gengar
1. use Drowzee assist "Quick Nap"
	( foe sleeps for exactly 1 turn )
2. use Gengar "Dream Eater"
	( recovers half damage done as HP if foe is asleep )

Kadabra + Slowbro
1. use Kadabra "Magic Spoons"
	 ( conjure 3 Magic Spoons with "Quickaction: Psychic moves deal 50% more damage this turn and have priority". They dissappear if your active pokemon is not a psychic user ) ( Note: conjured items work similar to hazards)
2. Switch into Slowbro and use Spoon + psychic move

Pidgeotto + Hitmonchan
1. Use Pidgeotto "Swift Swoop"
	 ( switch into another pokemon and give it +1 speed)
2. Use Hitmonchan "Quick Punch"
	 ( increased damage by speed )

Aipom + Machoke
1. Aipom – "Tag Flex"
    (switch out and give ally +1 Attack)
2. Machoke – "Power Slam" 
    ( Consume 1 power boost to crit )

 Jigglypuff + Clefairy
3. Jigglypuff – "Soothing Song"
    (heals allies on the bench slightly)
4. Clefairy – "Cosmic Dance"
    (Bonus damage if at least one ally has been healed this battle already)

Bellsprout + Vaporeon
1. Bellsproute "Blossom Switch"
	 ( switch out. Heal incoming ally )
2. Vaporeon "Waters of Life"
	( deals bonus damage if Vaporeon has been healed this battle )
